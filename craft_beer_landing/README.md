# Craft Wave — навчальний сайт-лендінг

## Тема сайту
Сайт-візитка / landing page для крафтової пивоварні **Craft Wave**.

## Структура проєкту

1. `index.html` — лабораторна робота 1, HTML:
   - структура сторінки;
   - шапка сайту;
   - навігація;
   - головний екран;
   - блок про пивоварню;
   - картки з видами пива;
   - опис процесу виробництва;
   - форма замовлення;
   - підвал сайту.

2. `style.css` — лабораторна робота 2, CSS:
   - кольорова схема;
   - оформлення карток;
   - адаптивна сітка;
   - кнопки;
   - відступи;
   - hover-ефекти;
   - адаптація під телефон.

3. `script.js` — лабораторна робота 3, JavaScript:
   - відкриття мобільного меню;
   - фільтрація видів пива;
   - калькулятор вартості дегустаційного набору;
   - перевірка форми замовлення.

## Як запустити сайт
1. Розпакувати архів.
2. Відкрити файл `index.html` у браузері.
3. Для редагування коду можна використовувати Visual Studio Code.

## Що можна сказати на захисті
У цій роботі було створено базовий веб-сайт типу landing page на тему крафтового пива. 
На першому етапі за допомогою HTML було сформовано структуру сайту: навігаційне меню, головний блок, інформаційні секції, картки товарів, форму замовлення та підвал. 
На другому етапі за допомогою CSS було оформлено зовнішній вигляд сторінки: підібрано кольори, створено адаптивну сітку, стилізовано кнопки, картки, форму та додано ефекти при наведенні. 
На третьому етапі за допомогою JavaScript було додано інтерактивність: мобільне меню, фільтр карток за категоріями, калькулятор вартості набору та перевірку заповнення форми.


## Оновлення зображень
У цій версії сайту до карток сортів пива додані реальні зображення банок, надані користувачем.
Зображення підключені у HTML через тег `<img>`, а в CSS для них задано клас `.beer-img`.
Кожне фото відповідає назві сорту в такому порядку:
1. Golden Lager
2. Citrus IPA
3. Dark Stout
4. Coffee Porter
5. Mango Hazy IPA
6. Cherry Sour


## Фінальна правка
У калькулятор вартості додано вибір конкретного сорту пива з окремою ціною за пляшку.
У формі заявки прибрано вибір стилю, тому користувач вводить тільки ім'я та телефон.


## Остання фінальна правка
Калькулятор вартості перероблено так, щоб можна було додавати декілька різних сортів пива одночасно.
Для кожного сорту вказується окрема кількість пляшок, після чого JavaScript автоматично рахує загальну кількість пляшок і підсумкову вартість.
